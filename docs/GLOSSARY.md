# 📖 พจนานุกรมคำศัพท์มาตรฐานของระบบ (Standard Glossary)

เอกสารฉบับนี้กำหนดมาตรฐานคำศัพท์ภาษาไทยที่ใช้แสดงผลในระบบติดตามเรื่องร้องเรียน สำนักงานเขตทวีวัฒนา เพื่อให้ทุกหน้า UI, รายงาน PDF, เอกสาร Excel และบันทึก Audit มีความสอดคล้องเป็นหนึ่งเดียวกัน

---

## 🏢 หมวดหมู่และหน่วยงาน

| คำศัพท์มาตรฐาน | คำอธิบาย / การใช้งาน | เลี่ยงการใช้คำ |
|---|---|---|
| **ฝ่ายในสังกัดเขตทวีวัฒนา (8 ฝ่ายหลัก)** | ฝ่ายปกครอง, ฝ่ายทะเบียน, ฝ่ายโยธา, ฝ่ายเทศกิจ, ฝ่ายรักษาความสะอาดฯ, ฝ่ายสิ่งแวดล้อมฯ, ฝ่ายรายได้, ฝ่ายคลัง, ฝ่ายการศึกษา, ฝ่ายพัฒนาชุมชนฯ | กอง, แผนก, สำนัก (สำหรับส่วนเขต) |
| **หน่วยงานภายนอก / หน่วยงานอื่น** | หน่วยงานที่ไม่สังกัดเขตทวีวัฒนา เช่น การไฟฟ้านครหลวง, การประปานครหลวง, กรมทางหลวงชนบท | นอกเขต, นอกระบบ |
| **รอจัดฝ่ายรับผิดชอบ** | เคสคงค้างที่ยังไม่มีชื่อฝ่ายในสังกัดเขตระบุใน `dept_list` (แสดงแยกบน Dashboard เพื่อให้ฝ่ายบริหารจัดสรร) | ไม่มีฝ่าย, เคสหลง, รอระบุฝ่าย |

## 📊 สถานะเรื่องและการปฏิบัติงาน (Case Lifecycle)

| สถานะ Traffy | ความหมายในระบบเขต | หมวดหมู่การคิดสถิติ |
|---|---|---|
| **รอรับเรื่อง** | เคสใหม่ที่เพิ่งถูกส่งเข้ามา ยังไม่มีฝ่ายกดรับ | 📥 รับเรื่องใหม่ |
| **รับเรื่อง** | ฝ่ายรับทราบเรื่องแล้ว อยู่ระหว่างวางแผนจัดการ | ⚡ ค้างปฏิบัติงานจริง |
| **กำลังดำเนินการ** | เจ้าหน้าที่กำลังลงพื้นที่ หรือกำลังแก้ไข | ⚡ ค้างปฏิบัติงานจริง |
| **ศึกษาปัญหา** | อยู่ระหว่างสำรวจ วิเคราะห์สาเหตุ หรือออกแบบ | ⚡ ค้างปฏิบัติงานจริง |
| **ของบประมาณ** | ต้องตั้งงบประมาณเพิ่มเติมเพื่อดำเนินการ | ⚡ ค้างปฏิบัติงานจริง |
| **จัดซื้อจัดจ้าง** | อยู่ในกระบวนการจัดซื้อจัดจ้างพัสดุ/งานจ้าง | ⚡ ค้างปฏิบัติงานจริง |
| **ขั้นตอนทางกฎหมาย** | อยู่ในกระบวนการบังคับใช้กฎหมาย/ดำเนินคดี | ⚡ ค้างปฏิบัติงานจริง |
| **ติดตามเรื่อง** | ดำเนินการแล้วเสร็จบางส่วน อยู่ระหว่างเฝ้าระวังผล | ⚡ ค้างปฏิบัติงานจริง |
| **เสร็จสิ้น** | ดำเนินการแก้ไขเรียบร้อยแล้ว | 🟢 เสร็จสิ้น |
| **ส่งต่อ(ใหม่)** | ส่งต่อให้หน่วยงานอื่นรับผิดชอบต่อ (หักออกจากภาระงานเขต) | 🌐 ส่งต่อภายนอก |
| **ไม่เกี่ยวข้อง** | ไม่ใช่ภารกิจของกรุงเทพมหานคร/สำนักงานเขต | ⚪ ไม่เกี่ยวข้อง |

## 📋 รอบรายงานและการตรวจหลักฐาน (Report & Evidence Workflow)

| คำศัพท์มาตรฐาน | ความหมาย / เงื่อนไข |
|---|---|
| **รอบรายงาน** | การ Snapshot เคสคงค้าง ณ วันที่กำหนด เพื่อนำส่งรายงานและติดตามหลักฐานรายสัปดาห์ |
| **พร้อม** / **รายงานครบถ้วน** | ทุกฝ่ายในรอบรายงานแนบเอกสารหลักฐานและได้รับการตรวจสอบอนุมัติเรียบร้อย |
| **ยังไม่ครบถ้วน** / **ต้องดำเนินการ** | ยังมีฝ่ายที่ยังไม่ได้อัปโหลดหลักฐาน หรือหลักฐานถูกตีกลับให้แก้ไข |
| **ร่างรอบรายงาน** (`draft`) | รอบรายงานที่เพิ่งถูกสร้าง ยังไม่ได้ประกาศเริ่มติดตามงาน |
| **ส่งติดตามแล้ว** (`sent`) | รอบรายงานถูกส่งออกให้ฝ่ายต่างๆ เริ่มเตรียมเอกสารหลักฐาน |
| **รอตรวจ** (`submitted` / `pending`) | ฝ่ายอัปโหลดหลักฐานแล้ว อยู่ระหว่างผู้ดูแลระบบหรือหัวหน้างานตรวจสอบ |
| **อนุมัติแล้ว** (`approved`) | ผู้มีอำนาจตรวจหลักฐานและยืนยันความถูกต้องเรียบร้อย |
| **ตีกลับ** (`rejected`) | หลักฐานไม่ครบถ้วนหรือไม่ถูกต้อง ส่งกลับให้ฝ่ายแก้ไขพร้อมแนบหมายเหตุ |
| **ถอนหลักฐาน** (`withdrawn`) | การขอยกเลิกหรือถอนไฟล์หลักฐานเดิมเพื่อเปลี่ยนไฟล์ใหม่ |
| **ปิดรอบถาวร** (`locked`) | รอบรายงานถูกล็อกการแก้ไขถาวร พร้อมจัดเก็บเข้าคลังถาวร |

## ⏱️ การติดตามอายุเรื่อง (SLA Thresholds)

| เกณฑ์ SLA | ช่วงระยะเวลา | ความหมาย |
|---|---|---|
| 🟢 **ปกติ** | 0 – 7 วัน | อยู่ในระยะเวลามาตรฐานการปฏิบัติงาน |
| 🟡 **เริ่มชะลอ** | 8 – 14 วัน | ควรเริ่มเฝ้าระวังและติดตามความคืบหน้า |
| 🟠 **เกิน SLA** | 15 – 30 วัน | เกินกรอบเวลาปกติ ต้องชี้แจงสาเหตุ |
| 🔴 **ค้างวิกฤต** | มากกว่า 30 วัน (> 30 วัน) | ต้องเร่งรัดและรายงานผู้บริหารเขตโดยด่วน |
